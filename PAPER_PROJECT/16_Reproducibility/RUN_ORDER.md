# RUN_ORDER

Exact order, with the command to run from the extracted archive root, what it reads, what it
writes, and the runtime the project recorded. Steps 0-5 reproduce the manuscript from the shipped
data; steps 6-9 recompute the data itself and are the expensive part.

## 0. Make the paths work (once per machine)

```bash
sh bootstrap_paths.sh
```

Reads: nothing. Writes: two symlinks. See "Path convention" in `README_PROGRAM.md`.

## 1. Integrity of the archive

```bash
cd PAPER_PROJECT_COMPLETE_REPRODUCIBILITY_ARCHIVE && sha256sum -c 09_ARCHIVE_METADATA/SHA256SUMS.txt
```

Every archived file except `SHA256SUMS.txt` and `file_manifest_sha256.csv` is covered.

## 2. Verification suite (stored results shipped; ~20 min to re-run)

```bash
python3 01_PROGRAM/tests/run_tests.py            # writes 07_Tests/TEST_RESULTS.json + logs
python3 01_PROGRAM/tests/run_tests_supplement.py   # the gamma=3.5 and direction studies
python3 01_PROGRAM/tests/make_test_report.py       # TEST_RESULTS.json -> TEST_REPORT.md
```

Reads: `src/` only. Writes: `07_Tests/TEST_RESULTS.json`, `TEST_REPORT.md`. The stored copies of
both are in `04_REPRODUCTION/`, including the one failing case (V0 on the hand-off 96x48 grid at
chi=2) and why it fails - the paper reports that failure, so a re-run is expected to reproduce it.

## 3. Convergence studies (optional; the shipped results are in `03_DATA/raw/`)

```bash
python3 01_PROGRAM/experiments/run_convergence.py         # gamma=5 family

python3 01_PROGRAM/experiments/run_convergence_dirs.py     # mesh-direction study
```

Writes: `09_Raw_Data/convergence*/` pairs of `.json`+`.npz` per run; read by `analyze_v2.py`.

## 4. Production matrix (optional; 150+ runs, 3 s to 157 s each)

```bash
python3 01_PROGRAM/experiments/run_production_v2.py heavy &
python3 01_PROGRAM/experiments/run_production_v2.py light &
```

Writes: `09_Raw_Data/production/<TAG>.json` + `<TAG>.npz`, plus a `block`/`grid` stamp per row.
The case list is generated by `01_PROGRAM/experiments/production_matrix.py` (`GRIDS`, `E_VARIANTS`,
`B_DEF`, `F_TW`, `BM_DEF` - see `parameter_manifest.json`).

## 5. Analysis, provenance, figures

```bash
python3 01_PROGRAM/experiments/analyze_v2.py         # -> 10_Processed_Data/ANALYSIS_V2.json
python3 01_PROGRAM/experiments/make_provenance.py    # -> PRODUCTION_PROVENANCE.csv
python3 01_PROGRAM/experiments/make_figures.py         # -> 11_Figures/fig*.png
python3 Phase_09_Closeout/verification/export_submission_figures.py   # 600-dpi PNG/TIFF + vector PDF
```

`make_figures.py` accepts specific names (`python3 ... fig2 fig5`) and skips figures whose data is
absent, printing `<name>: no data` - a partial `03_DATA/` therefore degrades visibly instead of
silently.

## 6. Manuscript and companion

```bash
cd PAPER_PROJECT/13_Manuscript

python3 ../01_PROGRAM_builders_placeholder 2>/dev/null || python3 build_manuscript.py

python3 build_calculations.py
python3 build_supplement.py
```

These three scripts take no options: each regenerates its document from the data and aborts before
writing if the deposited code-freeze manifest is no longer current (the guard was tested by
corrupting one entry). To check the freeze without touching anything, run the read-only
`python3 tools/connection_audit.py` from the archive root instead.
The preview PDFs are a separate, documented step - the builders write `.md`/`.docx`, and
`tools/md_to_pdf.py` renders the PDF with the running title baked into the header:

```bash
python3 tools/md_to_pdf.py -i PAPER_PROJECT/13_Manuscript/manuscript_IJHMT.md \
  -o PAPER_PROJECT/13_Manuscript/manuscript_IJHMT.pdf
python3 tools/md_to_pdf.py -i PAPER_PROJECT/13_Manuscript/calculations_IJHMT.md \
  -o PAPER_PROJECT/13_Manuscript/calculations_IJHMT.pdf
```

`reportlab` is not in the pinned requirements file (its version is NOT DOCUMENTED; the
sandbox that verified this archive had 5.0.1), so a different version can shift page breaks
- that is why `verify_pdf.py` compares text content, not bytes, and why the `.md` sources are
authoritative while the PDFs are previews.

Writers of the manuscript are `13_Manuscript/ms_*.py` (section modules) + `docbuilder.py`
(`.md` -> `.docx`/`.pdf`) + `tools/md_to_tex.py` (`.md` -> `.tex`). They read only `03_DATA/` and
`01_PROGRAM/`; they never hand-type a number, which is why a data change propagates.

## 7. Reproduction test and the QA gates

```bash
python3 01_PROGRAM/experiments/reproduce.py      # -> 07_Tests/REPRODUCTION_TEST_REPORT.md

python3 tools/audit_tex.py
python3 tools/connection_audit.py
python3 tools/verify_pdf.py   # manuscript: no -c
python3 tools/verify_pdf.py -p PAPER_PROJECT/13_Manuscript/calculations_IJHMT.pdf \
  -m PAPER_PROJECT/13_Manuscript/calculations_IJHMT.md -c        # no -r here, on purpose: the companion footer is the manuscript running title

python3 Phase_08_Final_Audit/verification/final_consistency.py
```

## 8. Packages

```bash
python3 00_Project_Control/make_packages.py final

python3 PAPER_PROJECT/00_Project_Control/make_reproducibility_archive.py   # this archive
```

Both archives are deterministic: same tree in, same bytes out (fixed entry stamps), so their
sha256 is a usable checksum of the project.

## Order constraints, in one line each

- `analyze_v2.py` before `make_figures.py` (figures read `ANALYSIS_V2.json`).
- `make_provenance.py` after any new production run (the CSV is the audit trail the manuscript cites).
- `build_manuscript.py` after figures and analysis (it embeds both).
- `make_code_freeze.py` LAST if you edited code, before packaging (the builders abort when the
  manifest is stale, by design).
