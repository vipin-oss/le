## Build

### CI

The workflow is [`.github/workflows/latex-build.yml`](.github/workflows/latex-build.yml). A push to an `arena/**` branch and pull requests targeting `main` run it; it can also be started with **Actions → LaTeX Build → Run workflow**. CI uses a prebuilt TeX Live container and installs only the small PDF/system utilities separately.

### Local Linux build

Install a complete TeX Live distribution providing `latexmk`, `pdflatex`, `bibtex`, and `pdffonts`; also install Python 3 with `venv`, Node.js 20/npm, Poppler utilities, and DejaVu fonts. From the repository root:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r phase5/tools/requirements-audit.txt
npm ci --prefix phase5/tools
bash phase5/scripts/build_master.sh
```

The build writes `phase5/master/build/main.pdf` and diagnostic logs beneath `phase5/master/build/`. Do not treat a successful compile as a scientific or submission-readiness certification.

## What is not in this repository

Publisher PDFs and extracted publisher full texts are not included in the current tree. The 51 tracked full-text extraction files and their 51 duplicate members in the legacy v1.0 bundle were removed; only path/disposition records remain in the exclusion table. Missing source materials have not been recovered or used; the archived checkpoint records do not stand in for them. The PDFs that remain are project-generated manuscript baselines/build outputs and vector figure assets, not copies of publisher papers.

## Known limits

- The 457-row open-claim ledger and 593-row deletion audit are tracking records, not replacements for the lost 96-claim matrix, defect register, D4/D5 packet, or 43 test scripts; see [`KNOWN_LOSSES.md`](KNOWN_LOSSES.md).
- Class B/C entries remain open until the specific claim, source identity, and supporting equations/results are checked. Do not infer verification from a bibliography match or metadata response.
- The classical flux derivation is conditional on its stated assumptions; generalized, nonlocal, fractional, and multiphysics energy claims remain partly open or model-specific.
- Figure authorship/licensing provenance and final-size legibility are not fully established. Contact sheets are overview checks, not page-by-page proofing.
- The phase4 baseline and archive contain historical context. They do not restore missing October work or provide the absent source archive.
