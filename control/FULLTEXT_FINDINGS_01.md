## F1. GREEN & LINDSAY 1972 — THE MANUSCRIPT'S EQ. (4.9) DOES NOT MATCH THE ORIGINAL (important; overturns Claude's arbitration of W1 in part)
Primary text (J. Elasticity 2:1-7), linear theory, section 4, eqs (4.11) and (4.13) and condition (4.9)/(4.14):
- Stress: t_ik = k_iklrs e_rs + a_ik (theta + alpha*thetadot). [so tau_1 = alpha sits in the stress]
- Heat flux: q_i = -theta_0 (b_i thetadot + k_ij theta_,j). With a centre of symmetry b_i = 0, so q is FOURIER: there is NO flux relaxation. [confirms "GL has no flux relaxation"]
- Entropy: rho_0 eta = a + d*theta + h*thetadot - a_ij e_ij - b_i theta_,i. Hence the linear energy equation (4.13) reads (source-free) k_ij theta_,ij - d*thetadot - h*thetaddot + a_ij edot_ij = 0, i.e. the temperature carries (thetadot + (h/d) thetaddot) [tau_0 = h/d] but the STRAIN-RATE COUPLING TERM a_ij edot_ij CARRIES NO RELAXATION TIME (no eddot term).
- Entropy-production restriction (4.9)/(4.14): d*alpha - h >= 0, i.e. alpha >= h/d, i.e. tau_1 >= tau_0 (tau_0 = h/d, tau_1 = alpha); (4.16) adds d, h, alpha > 0.
So the ORIGINAL GL isotropic system is: sigma_ij = 2 mu e_ij + [lambda e_kk - beta (T + tau_1 Tdot)] delta_ij; k lap T = rho c_E (Tdot + tau_0 Tddot) + beta T_0 edot_kk (no tau_0 on the strain-rate term); tau_1 >= tau_0 >= 0 (strictly >0 by 4.16).
The manuscript's (4.9) (phase5/master/sections/sec04_thermoelastic.tex:~101) has beta*T_0*(udot_ii + tau_0 uddot_ii): the coupling term carries tau_0 as in LS. That is the LS energy equation combined with the GL stress law: it is a later hybrid/variant used in parts of the literature, NOT Green-Lindsay 1972. Brave's three "slot-for-slot" matches (Bera et al., Singh 2020, preprint) compared the manuscript with those papers, not with the original: they show the variant exists, not that it is GL's. Consequences:
 (a) Brave's W1 charge (4.9 is a verbatim copy of the LS energy equation) is PARTLY RIGHT, though its stated reason (same tau must appear) was wrong. Claude's arbitration "NOT ACCEPTED" was too strong; Claude relied on a secondary recollection. Corrected verdict: eq (4.9) is WRONG AS A STATEMENT OF GL 1972 (extra tau_0 on the coupling term); it can be kept only if labelled "a commonly used variant with a uniform (d/dt + tau_0 d^2/dt^2) operator on the strain-rate term" with the original stated next to it.
 (b) Lord-Shulman, for comparison (primary, eq 23): k lap T = rho c_E (Tdot + tau_0 Tddot) + (3 lambda + 2 mu) alpha_T T_0 (edot + tau_0 eddot): the coupling term DOES carry tau_0 in LS. So the LS/GL difference in the coupling term is real and must be shown in the review, in a comparison table.
 (c) Rigid GL thermal speed sqrt(kappa/tau_0) is unaffected. The coupled GL secular equation and everything that depends on it (Brave V-B2c R7/R8, V-B3 interface numbers for GL, Arena eq (9.9) if GL-specific, GL rows in tables) must be recomputed with the correct coupling; in the coupled dispersion the coupling product carries the stress factor (1 - i omega tau_1) and no heat-equation factor.

## F3. QUINTANILLA & RACKE 2006: Taylor-expanded DPL, second order in tau_q and first order in tau_theta: system stable if tau_theta/tau_q > 1/2, unstable if < 1/2 (Conclusion, as printed in the paper). The paper compares this with the model first-order in both and states the parameter regions differ. Confirms Brave's V-B2p and Claude's own Routh-Hurwitz re-derivation. PRIMARY-SOURCE-CHECKED.

## F4. WANG & LI 2011: the memory-dependent derivative is an integral of the ordinary derivative against a kernel K(t-s) on a sliding window of length tau, and "the kernel can be chosen freely" (examples given: 1, s-t+1, [(s-t)/tau+1]^2, [(s-t)/tau+1]^(1/4)). So any model using it must state tau AND K; Fourier symbol only for K=1. Confirms W3 / MDD pitfalls. PRIMARY-SOURCE-CHECKED.
