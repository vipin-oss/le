## F19 Quintanilla 2019, Math. Mech. Solids 24(12):4020-4031, DOI 10.1177/1081286519862007 (OA copy: UPCommons)
- Intro: type III law q_i = k* alpha,i + k theta,i (alpha-dot = theta); k*=0 -> type I; k=0 -> type II. Adding relaxation gives (1.3) tau q-dot_i + q_i = k* alpha,i + k theta,i; with energy q_i,i = c theta-dot this gives the linear MGT equation; k*=0 recovers Cattaneo-Maxwell. Printed sign convention: q here is minus the usual heat flux (energy eq q_i,i = c theta-dot).
- (2.4) tau q-dot_i + q_i = k_ij theta,j + k*_ij alpha,j ; (2.5) tau c theta''' + c theta'' = (k*_ij theta,i),j + (k_ij theta-dot,i),j ; defines K_ij = k_ij - tau k*_ij. Note: (2.1) writes the k* term with alpha,j while (2.5),(3.5) write it with theta,j; the paper itself does not reconcile this (differentiated form).
- (3.1) t_ij = C_ijkl u_k,l - beta_ij theta, eta = c theta + beta_ij u_i,j ; (3.4) momentum rho u-ddot_i = (C u_k,l - beta theta),j ; (3.5) c theta'' + c tau theta''' = -beta_ij (u-ddot_i,j + tau u-dddot_i,j) + (k_ij theta-dot,j),i + (k*_ij theta,j),i. (theta form: coupling beta (u'' + tau u''') consistent with GN-II finding F17.)
- STABILITY: 3D: (2.8) k*_ij xi xi >= k0 |xi|^2 and (2.9) K_ij xi xi = (k_ij - tau k*_ij) xi xi >= k1 |xi|^2; energy identity (2.11); contraction semigroup (Lemma 3.1, Thm 3.3), well-posedness (Thm 3.4). 1-D: (4.5) c,rho,mu,k*>0, beta != 0, tau>0 and k > k* tau => exponential stability (Thm 4.7, Liu-Zheng). k < k* tau => instability (Sec 5, (5.8) Lambda2 = n^2 c (k/tau - k*) <0). MGT can also be obtained from TPL under a tau-approximation (2.15).
- CONSEQUENCE: the thermoelastic MGT admissibility is k - tau k* > 0 (in these printed symbols, k = Fourier conductivity, k* = rate conductivity). My earlier note "gamma = b - tau c^2 > 0" belongs to the gas-dynamics acoustic form (Moore-Gibson) and must NOT be quoted for the thermoelastic MGT. Manuscript eq (51) (tau q-dot + q = -kT,i - k* theta_m,i, theta_m-dot = T) is the same law in the usual heat-flux sign: its "unverified source lead" label can be upgraded to PRIMARY-SOURCE-CHECKED for the constitutive form, K=k-tau k*>0 and the 1-D decay/instability dichotomy; NOT for 3D exponential decay rates (not printed there).

## F20 Bazarra-Fernandez-Quintanilla 2021, Math. Mech. Solids, DOI 10.1177/1081286521994258 (radial decay)
- (1) rho u-ddot_i = mu u_i,jj + (lambda+mu) u_j,ji - beta(theta,i + tau theta-dot,i) [stress carries tau: a second MGT variant]; (2) c(tau theta'' + theta-dot) = k* lap alpha + k lap theta - beta u-dot_r,r (alpha form: coupling u-dot, one derivative: consistent with F17).
- Assumed (5): rho,mu,c,k*,tau>0, lambda+2mu>0, k-bar = k - tau k* > 0. Gives decay for radial solutions. Different MGT thermoelastic variants coexist: with and without tau in the stress law.

## F21 Mindlin 1974, Int. J. Solids Structures 10:625-637 (thermopiezoelectric plates), from page render
- Classical linear thermopiezoelectricity: (1) T_ij,i = rho u-ddot_j, D_i,i = 0, h_i,i = -Theta0 eta-dot; (2) S_ij = (u_i,j+u_j,i)/2, E_i = -phi,i, h_i = -K_ij theta,j (FOURIER law); (3) T_ij = dG/dS_ij, D_i = -dG/dE_i, eta = -dG/dtheta, G electric Gibbs function; (5) T_ij = c_ijkl S_kl - e_kij E_k - lambda_ij theta ; D_j = e_jkl S_kl + eps_jk E_k + p_j theta ; eta = lambda_kl S_kl + p_k E_k + alpha theta, alpha = rho C_E / Theta0.
- Reduced (27 -> 5 unknowns): c_ijkl u_k,lj + e_kij phi,ki - lambda_ij theta,i = rho u-ddot_j ; e_kij u_i,jk - eps_ij phi,ij + p_i theta,i = 0 ; lambda_ij u-dot_i,j - p_i phi-dot,i + alpha theta-dot = Theta0^-1 K_ij theta,ij. Energy principle (6) analogous to Biot's variational principle.
- CONSEQUENCE for s.5: this is the classical (Fourier) thermopiezoelectric base: any generalized (LS/DPL/TPL/MGT) piezothermoelastic model replaces h_i = -K theta,j by a lagged law; the equations above are a checkable limit. Printed sign/index conventions differ across papers (theta,i vs theta,j in first eq) - check index contraction before quoting.
