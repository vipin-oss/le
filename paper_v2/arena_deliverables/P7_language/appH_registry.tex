\section{Benchmark registry}\label{app:registry}
\Cref{tab:registry} lists the fourteen benchmarks run by \path{run_checks.py}. Every entry is a \emph{code verification}: it tests that an implementation reproduces an exact, closed-form, symbolic or independently computed reference to a stated tolerance. None is a \emph{physical validation}, because this review reports no new experiment, and validation against measured data is limited by the evidence discussed in \cref{sec:experiments}. The registry is also available as a machine-readable file (\path{benchmark_registry.csv}) in the scripts directory, with the script implementing each entry. A new model or solver should join the registry with (i) a reference solution that does not use the code under test, (ii) a tolerance and the reason for it, and (iii) a statement of what a pass does \emph{not} establish.

\paragraph{What the registry does not cover.} Entries B01--B14 use implementations written by the authors. Except for B01 and B08, whose references are symbolic, the reference solutions are closed forms or an independent algorithm rather than a second independently written code base, and an independent implementation by another group remains open.
