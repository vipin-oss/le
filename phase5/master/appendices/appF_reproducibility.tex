\section{Reproducibility and evidence status}
\label{app:reproducibility}

This appendix describes the status of the repository materials accompanying this revision; it is not a claim that every result in the manuscript has been reproduced. The working bibliography is \texttt{references\_local.bib}. Literature metadata is drawn from the repository inventory and selected DOI checks. DOI resolution is bibliographic verification only. It does not establish that a source was read in full or that a particular equation, interpretation, or numerical result has been checked against that source.

The versioned source bundle contains the LaTeX manuscript, embedded table sources, editable SVG figures, and generated PDF figure assets. The baseline PDF is separately identified as \texttt{v1.0-baseline.pdf}; it is not a rendering of the edited source in this directory. The repository copy of that PDF is 161 pages with embedded metadata identifying pdfTeX 1.40.25 and a 2023-11-14 creation date; the separately described 170-page/pdfTeX-1.40.29 attachment is not available in this workspace, so its provenance cannot be reconciled here. A local TeX engine remains unavailable, but strict CI run 39771440399 compiled the v1.1 source, passed the strict build gates, and published the 149-page PDF and contact sheets; its source commit was ce7bba4550b69dca8d213bf860b153224726f564. The CI report records 483 underfull hbox warnings and zero underfull vbox warnings. Eighteen SVG figures were converted to PDF with the pinned Node renderer; CairoSVG was unavailable because its native Cairo library could not be loaded. Source files, commands, and limitations are recorded in \texttt{../README\_build.md} and \texttt{../reports/build-status.md}.

The engineering and scientific audit registers distinguish the limited calculations checked directly from claims that remain conditional, unverified, or open. Specifically, the classical local energy balance is re-derived in Sections~3 and Appendix~B under an outward-positive convention; the other family-specific balance identities and all newly asserted benchmark values remain outside the verified set unless an explicit derivation and source record is provided. The literature search is not a systematic review, and no screening flow diagram or comprehensive database query is claimed.

All tables and figure artwork are editable source, and the manuscript's 18 distinct figure references resolve to generated PDFs in the self-contained master tree. Static XML/PDF checks and the strict manuscript build passed. The four contact sheets and selected full-page renders were reviewed for gross layout and clipping; they do not constitute an exhaustive final-size typographic or scientific proof. No generated numerical data, fit, or independent benchmark dataset is represented as completed evidence.
