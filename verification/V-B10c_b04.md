## Method

1. Roster and Drive IDs from `DRIVE_PRIORITY.csv`.
2. `google_drive__download_file` per ID. **New, decisive method change:** the connector writes each
   PDF into the workspace (`google_drive/<name>.pdf`), so the file can be moved to `/tmp` and
   extracted **locally** with `pypdf` 6.21.2. This removes the earlier limitation where the Drive
   read tool truncated a long paper at a fixed character budget (it is what had left Megahid 2023
   at PARTIAL in B01). The workspace directory is removed at the end of the batch.
3. Targeted `grep -a` on each extraction for the nonlocal operator (`(1 − …∇²)`, `e0a`, `ε`, `ξ`,
   `(ea)²`), the flux law, the fractional or memory kernel, and the printed ordering text.
4. Papers were read at law level first (operator + flux law + field equations); anything beyond
   that is tagged PARTIAL in the row rather than assumed.
5. Metadata taken from the title page; where the file lacks the journal/DOI, the paper is **not**
   added to `LITERATURE_BASE.csv` (see open issues).

## Result

### B04-1 — the GN-III law is now printed, and it confirms the structure test proposed in B03

**Biswas 2020** (*Acta Mechanica*, doi:10.1007/s00707-020-02670-2), porous nonlocal thermoelasticity
in Green–Naghdi **type III**, prints the flux law at **eq. (19)** with the nonlocal operator outside
and **both** conductivities inside: the temperature gradient with `K_ij` **and** the
thermal-displacement gradient with `K*_ij`. Component forms at (24)–(26).

B03 concluded that GN-II and GN-III cannot be separated by the absence of a first-order term —
both are undamped — and predicted that the discriminator is a second, independent coefficient on
the thermal-displacement (or temperature-Laplacian) term. Eq. (19) here is that discriminator,
printed. §4.5–4.6 can now be written with a verified GN-III form and with the year-attribution
caveat kept separate, which is exactly the split B03 recommended.

### B04-2 — operator placement in the §7 literature: four classes, not one

The batch makes the taxonomy unavoidable. Printed placements:

| paper | eq | where the operator sits |
|---|---|---|
| Biswas 2020 (DRV-0106) | (13), (19) | kernel, then the **whole flux law** (`K T_,j + K* ν_,j`), and also the constitutive set (14)–(17) |
| Bachher & Sarkar 2019 (DRV-0150) | (18) | the **whole fractional Cattaneo law**, operator outside the relaxation bracket |
| Gupta et al. 2024 (DRV-0034) | (22) **and** (25) | **both** the inertia and the whole fractional MGT flux law |
| R. Kumar et al. 2023 (DRV-0050) | (2.1)–(2.4) | **inertia only**, one parameter per field (three here) |
| S. Gupta, Das & Dutta 2021 (DRV-0088) | (12)–(15) | **constitutive set only** (stress and both pore pressures) |
| Faleh & Abboud 2020 (DRV-0117) | (17)–(21) | **constitutive set only**, extended to electric and magnetic fields |

The manuscript's eq. (7.2) is the last class, single-field. §7 currently describes nonlocality as if
that were the only placement. It is not, and two of the counterexamples are own-group papers. §7
needs either an explicit restriction ("the differential Eringen form used in this review") or a
placement table. §9.7 follows from the same point: a nonlocal interface/energy statement cannot be
transferred between classes.

### B04-3 — the defective fractional `α → 0` branch is a cluster convention, not a slip

**Bachher & Sarkar 2019**, eq. (18) and the definition following it, print the same three-branch
fractional derivative whose `α → 0` branch is "the function minus its initial value" that B03
flagged in DRV-0009. Two independent groups, same defective branch. The manuscript must therefore
avoid the branch as a matter of policy (it already does), and §4.11 should not present the
`α → 0 → Fourier` limit as automatic for this convention family.

### B04-4 — the second-order lag coefficient is sometimes a free parameter

**R. Kumar et al. 2023**, eq. (2.5): the flux-side bracket carries `τ_q ∂/∂t + a₀(τ_q²/2)∂²/∂t²`
with `a₀` a **tunable coefficient**, and §2.1 states the DPL window as `0 < τ_T < τ_q` with
`a₀ = 1`, LS at `τ_T = a₀ = 0`, classical at both lags zero, and local DPL when all four nonlocal
parameters vanish. This is stronger support for the manuscript's §4.8 wording ("declared
truncation") than sources that fix the coefficient at ½: here even the coefficient is a choice, and
the source says so. It is also the only paper in this batch with a **printed ordering inequality**.

### B04-5 — four items cannot be closed on the evidence in the file

* **DRV-0112** (Cheng Li, axially moving piezoelectric nanobeam): the file carries no journal,
  volume or DOI — it is a manuscript-style copy. Title, author and model description are readable;

* **DRV-0088** (S. Gupta, Das & Dutta, irregular FGFPM structure): operator equations (11)–(15)
  read cleanly, but the journal and DOI are not printed in the file. Not added to the base.
* **DRV-0212** (Yadav, Carrera, Marin & Othman, *Mech. Adv. Mater. Struct.*): the article header is
  visible but the DOI is not in the extracted pages; the integral constitutive set (12)–(16) was
  read. Not added to the base until the DOI is confirmed from the title page.
* **DRV-0151**: this is not a paper. It is the SIAM CBMS-NSF monograph *Nonlocal Modeling, Analysis
  and Computation* (174 pp.). Only front matter was inspected. It cannot serve as a primary source
  for a model form in §7 and is recorded as **UNVERIFIED / not read**, not as coverage.

Adding any of the first three to the base would require inventing a journal, a DOI or a volume.
They are held out deliberately; the base keeps its rule that every DOI in it was printed in the
document it points to.
