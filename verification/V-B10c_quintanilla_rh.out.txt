==============================================================================
1. SYMBOLIC ROUTH-HURWITZ TABLE (quartic, exact rational arithmetic)
==============================================================================

--- N1 (c0 = k) ---
first column: a0, a1, b1, c1, a4
  a0 = tau_q**2/2
  a1 = tau_q
  b1 = k*lam2*tau_T - lam2*tau_m*tau_q/2 + 1
  c1 = lam2*(-2*k*tau_q + tau_m*(2*k*lam2*tau_T - lam2*tau_m*tau_q + 2))/(2*k*lam2*tau_T - lam2*tau_m*tau_q + 2)
  a4 = k*lam2
  b1 > 0  <=>   2*k*lam2*tau_T - lam2*tau_m*tau_q + 2  > 0
  c1 > 0  <=>   lam2*(2*k*lam2*tau_T*tau_m - 2*k*tau_q - lam2*tau_m**2*tau_q + 2*tau_m)  > 0
  c1 numerator / (tau_q*lam2) = (2*k*lam2*tau_T*tau_m + 2*tau_m - tau_q*(2*k + lam2*tau_m**2))/tau_q
  as  P + lam2*Q :  P = -2*k + 2*tau_m/tau_q    Q = tau_m*(2*k*tau_T - tau_m*tau_q)/tau_q

--- N2 (c0 = k*/k) ---
first column: a0, a1, b1, c1, a4
  a0 = tau_q**2/2
  a1 = tau_q
  b1 = k*lam2*tau_T - lam2*tau_m*tau_q/2 + 1
  c1 = lam2*(k*tau_m*(2*k*lam2*tau_T - lam2*tau_m*tau_q + 2) - 2*k_star*tau_q)/(k*(2*k*lam2*tau_T - lam2*tau_m*tau_q + 2))
  a4 = k_star*lam2/k
  b1 > 0  <=>   2*k*lam2*tau_T - lam2*tau_m*tau_q + 2  > 0
  c1 > 0  <=>   lam2*(2*k**2*lam2*tau_T*tau_m - k*lam2*tau_m**2*tau_q + 2*k*tau_m - 2*k_star*tau_q)  > 0
  c1 numerator / (tau_q*lam2) = (2*k**2*lam2*tau_T*tau_m + 2*k*tau_m - tau_q*(k*lam2*tau_m**2 + 2*k_star))/tau_q
  as  P + lam2*Q :  P = 2*k*tau_m/tau_q - 2*k_star    Q = k*tau_m*(2*k*tau_T - tau_m*tau_q)/tau_q

READING OF THE SYMBOLIC RESULT
  The two non-trivial Routh conditions are
     (R1)  P + lam2*Q > 0  for every lam2 > 0
     (R2)  which, since a0,a1,a2,a3,a4 > 0 already holds, is the whole condition.
  For both normalisations this splits into
     P > 0   ->  tau_m > tau_q * c0        (lower bound, proportional to the T-coefficient)
     Q >= 0  ->  tau_m <= 2*k*tau_T/tau_q  (upper bound, INDEPENDENT of the normalisation)

General symbolic condition for the constant term c0 = C:
   [tau_m - tau_q*C] + lam2*[tau_m*(k*tau_T - tau_m*tau_q/2)] > 0 for all lam2 > 0
   <=>  tau_m > tau_q*C   and   tau_m <= 2*k*tau_T/tau_q.
N1 (C=k)          -> (tau_q*k, 2*k*tau_T/tau_q)
N2 (C=k*/k)       -> (tau_q*k*/k, 2*k*tau_T/tau_q)
N3 (C=k/k*)       -> (tau_q*k/k*, 2*k*tau_T/tau_q)   <-- EXACTLY the printed eq (1.2)

The switch of sign of max Re(s) happens exactly at the two predicted edges
(to within the 1e-3 relative offset used for the test points), so the window is
confirmed for the normalisation c0 = k.  The upper edge 2*k*tau_T/tau_q is
normalisation-independent; the lower edge scales with c0.
