## 2. The controls are what make the negatives usable

A single "not found" from a fetch tool proves nothing — the tool may simply be failing for
APS DOIs. The order therefore demanded controls on the same routes. All five controls
succeeded:

| Control | Route | Result |
|---|---|---|
| `10.1103/PhysRev.133.A1411` (Guyer & Krumhansl 1964, "Dispersion Relation for Second Sound in Solids", Phys. Rev. **133**(5A) A1411–A1417, 1964-03-02, cited-by 131) | Crossref `/works/` | `200`, full JSON |
| same | OpenAlex, ORed into the same `filter=doi:` expression as the target | `200`, `count: 1` — **only the control present** |
| same | Semantic Scholar | `200`, found |
| `10.1103/PhysRev.131.2013` (Chester 1963, "Second Sound in Solids", Phys. Rev. **131**(5) 2013–2015, 1963-09-01, cited-by 553) | Crossref `/works/` | `200`, full JSON |

The ORed OpenAlex request deserves emphasis: because the target and the control went into
**one** filter expression and only the control came back, the parser is demonstrably
working and the zero is a real absence rather than a malformed query.

## 3. Answer to the order's direct question

> "What would a Guyer+McCracken record, if any, be?"

There is no such record in any index consulted. The real second-sound work by R. A. Guyer is
jointly with **J. A. Krumhansl** (Phys. Rev. 133 A1411, 1964; Phys. Rev. 148, 778, 1966) and
with **J. E. McClintock and H. H. Mueller** (Phys. Lett. A, 1968). The name *McCracken* does
not attach to any of them. The claimed article title "Second sound in solids" is a real
title — but it is **Chester 1963**, Phys. Rev. 131, 2013, not a 1990 PRA paper.

The most likely artefact, stated as inference only: a real title, a real general topic and a
plausible-looking but non-existent DOI were fused into one record, and the DOI was then
"checked" by a validator that never performs a lookup.

## 4. Why Arena's table says YES

`scripts/validate_references.py` (fetched from `origin/arena/40393d9f-le`) checks only:
DOI **syntax** against a regex, duplicate DOIs, and the allowed status labels. It makes no
network call. Therefore the `crossref_match` column in `doi_verification.csv` is a
**self-asserted label, not a lookup result** — for Guyer1990 and for all 47 other rows
marked YES.

Corroboration of the finding, incidentally: Guyer & Krumhansl's own 1964 reference list cites
both Chester 1963 and Vernotte C. R. **246**:3154 — independently confirming the B5a
`Vernotte1958` page-range correction.

## 6. What this does not licence

This proves one row wrong. It does **not** prove the other 47 YES rows wrong — they were
tested separately (`V-B5b_arena_method_reclassification.csv`) and 44 of them hold up. It does
establish the weaker but important point that **Arena's verification column cannot be used as
evidence**; only a lookup can.
